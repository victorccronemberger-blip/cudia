# Findings report

Use existing evidence; additional exploitation is not needed to write a report.
For each finding include affected asset/version or source location, triggering
conditions, evidence-supported severity, minimal reproduction, observed result,
realistic impact, remediation, and validation limits.

Keep confirmed behavior, source-supported defects, suspected issues, and
untested suggestions distinct. Reference evidence paths; redact secrets and
unrelated personal data. No findings or incomplete coverage with a concrete
blocker are valid outcomes. Follow the requested format and save a file when
the deliverable calls for one.
