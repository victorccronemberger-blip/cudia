Read a file or directory from the local filesystem. If the path does not exist, an error is returned.

Usage:
- The filePath parameter should be an absolute path.
- By default, this tool returns up to 2000 lines from the start of the file. The complete text response is also capped at 50 KiB and 2000 lines, or lower configured limits, including line numbers and notices.
- The offset parameter is the line number to start from (1-indexed).
- To read later sections, call this tool again with a larger offset.
- For directories, start at offset 1 and continue with the returned offset and snapshot. If the listing changes, restart at offset 1 without snapshot. A directory scan exceeding 100000 entries or 16 MiB of entry metadata fails explicitly.
- Use the grep tool to find specific content in large files or files with long lines.
- If you are unsure of the correct file path, use the glob tool to look up filenames by glob pattern.
- Contents are returned with each line prefixed by its line number as `<line>: <content>`. For example, if a file has contents "foo\n", you will receive "1: foo\n". For directories, entries are returned one per line (without line numbers) with a trailing `/` for subdirectories.
- Any line longer than 2000 characters is abbreviated. Use textPage for exact text; the normal read stops without scanning the remainder of an overlong line. Total line counts are included only when the end of the file is known.
- Call this tool in parallel when you know there are multiple files you want to read.
- Avoid tiny repeated slices (30 line chunks). If you need more context, read a larger window.
- This tool can read image files and PDFs up to 20 MiB and return them as file attachments. This ingestion limit is separate from image resizing and text response limits.
- Nearby project instructions are delivered first in bounded batches without the requested file or attachment. Retry the original read after receiving each batch. An instruction document too large for automatic delivery returns an explicit error. Explicit textPage reads remain available; complete matching instruction pages must remain in selected context before the target can be released.
- textPage: {} reads exact text without the line-length cutoff. Continue with textPage: {offset: nextOffset, contentHash: "..."}; offsets are UTF-16 code units. A changed file requires restarting at offset 0. Do not combine textPage with line offset/limit.
