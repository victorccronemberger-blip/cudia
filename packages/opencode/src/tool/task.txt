Run a prompt in an agent session selected by subagent_type. Without task_id, the tool creates a new child session. With task_id, it continues the existing session; if lookup fails, it reports the error and does not create a replacement. A new session receives the supplied prompt, agent configuration and selected model; it does not copy the parent's conversation.

Foreground calls wait for the result. When background mode is available, background=true returns a running task immediately and the runtime posts its completion or error to the parent session. Results include the child session ID and a running, completed or error state for follow-up.
